# DE B1 RPG Studio

Telegram Mini App та інтерактивна вебгра для вивчення німецької мови (рівні A2/B1) з елементами RPG.

## Структура проєкту
- `index.html` — головна чиста розмітка.
- `css/` — модульні стилі (main, components, animations).
- `js/` — модульна архітектура ES6 (app, state, storage, telegram, cards, vocabulary, exam, audio, speech, xp, ui, utils).
- `data/words.json` — словникова база даних.

## Запуск
Просто відкрийте `index.html` через Live Server у VS Code або розгорніть у середовищі Telegram WebApp.
