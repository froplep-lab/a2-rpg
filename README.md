# GESTALT v0.021

Premium mobile-first German vocabulary trainer for Telegram Mini Apps.

## Основний цикл
Картка → перевірка → «Знаю / Не знаю» → spaced repetition → повторення → прогрес.

## v0.021
- Оновлена Mochi-подібна SRS-схема з 7 рівнями інтервалів: 1 / 3 / 7 / 14 / 30 / 60 днів.
- «Не знаю» повертає слово в активне навчання та планує коротке повторення через 10 хвилин.
- Статуси Нове / У процесі / На повторенні / Вивчене тепер рахуються з єдиного SRS-стану.
- Для словника додано IPA-вимову, згенеровану локально через eSpeak.
- Приклади карток із шаблонних заглушок замінені на прості контекстні A2-речення.
- Покращене відображення довгих німецьких слів без переносу всередині слова.
- Форма множини відокремлена від головного слова.
- Додано перемикач транскрипції.
- Збережено Telegram CloudStorage, локальне збереження, озвучку, навігацію, статистику, колекції та офлайн-кеш.

## Запуск
```bash
npm install
npm test
npm run check
npm run start
```

Для Telegram Mini App використовуйте HTTPS URL та server/.env з BOT_TOKEN і MINI_APP_URL.
